# IP strategy checklist

- Maintain immutable release archives and SHA-256 manifests.
- Keep inventor/contributor records and dated technical notebooks.
- Separate public reproducibility material from any confidential enabling implementation.
- Have counsel identify potentially patentable apparatus, control methods, computational methods, and system integration claims.
- File appropriate applications before publishing material that counsel identifies as patent-sensitive.
- Do not describe GitHub publication as a patent grant or exclusive right.
- Review third-party components and licenses before commercial deployment.
