# Legal and IP status

This file is a research/IP record, not legal advice.

1. Repository copyright and license terms govern the published code and documentation.
2. A proprietary license does not automatically prevent independent implementation of an underlying concept.
3. Patentability, novelty, inventive step/non-obviousness, enablement, ownership, inventorship, freedom-to-operate, and filing strategy require qualified patent counsel.
4. Public disclosure can affect patent rights differently across jurisdictions. Patent counsel should determine filing order and any applicable grace periods before publication of sensitive enabling details.
5. Git commits, release archives, hashes, CI logs, and manifests can preserve provenance, but they are not substitutes for patent applications or assignments.
